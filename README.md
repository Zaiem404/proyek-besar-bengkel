**PLANNING**
A. information

1. Typography (Font)
   Menggunakan font Poppins sebagai jenis huruf utama untuk memberikan tampilan yang modern, bersih, dan mudah dibaca oleh pengguna.
2. Color Palette (Warna)
   Menggunakan warna dasar Natural White sebagai warna utama untuk menciptakan kesan minimalis, bersih, dan nyaman saat pengguna menjelajahi website.
3. Website Niche (Kategori Website)
   Website ini berfokus pada bidang E-Commerce perlengkapan dan kebutuhan bengkel motor, yang menyediakan berbagai produk seperti oli mesin, suku cadang, aksesori, serta peralatan bengkel lainnya.
4. Tata letak (layout website)
   website ini dirancang agar responsive agar dapat muncul pada tampilan menyesuaikan layout layar. baik pada perangkat android, maupun desktop agar sesuai dengan rancangan yang dibuat
